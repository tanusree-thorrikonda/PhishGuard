# PhishGuard – Static URL Phishing Detection Platform

PhishGuard is a full-stack cybersecurity web application that analyzes suspicious URLs using static lexical heuristics without executing external network requests against untrusted hosts.

## Tech Stack
- **Backend:** Python 3, Flask, Flask-CORS, SQLite3, Pytest
- **Frontend:** React 18, Vite, Tailwind CSS, React Router, Recharts, Lucide Icons

## Quick Start
1. **Backend:** `cd backend && venv\Scripts\activate && python app.py`
2. **Frontend:** `cd frontend && npm run dev`
