# PhishGuard

## Project Overview

PhishGuard is an intelligent phishing URL detection
and cyber threat analysis platform.

It analyzes submitted URLs and identifies suspicious
characteristics using URL parsing and rule-based
detection techniques.

## Problem Statement

Phishing attacks use deceptive URLs to trick users
into visiting malicious websites and sharing
sensitive information.

Users need a simple platform that helps identify
potentially suspicious URLs before interacting
with them.

## Proposed Solution

PhishGuard allows users to submit URLs and analyzes
their structure using predefined detection rules.

The application calculates a heuristic risk score
between 0 and 100 and classifies URLs into:

- Low Risk
- Suspicious
- High Risk

It also explains the suspicious indicators found.
